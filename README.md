# 拾景

把一趟旅行的照片收成一篇图文。照片留在原来的顺序里，中文排在图下面，只有一页另画成插图。视频是这篇图文自己往下播。

这一版只在本机运行。界面是中文。没有账号、云同步、备份包，也不往外发布。

## 启动

在项目目录运行：

```bash
python3 server.py
```

浏览器打开 [http://127.0.0.1:8765](http://127.0.0.1:8765)。服务只听 `127.0.0.1`。

画画和读照片用的钥匙放在环境变量 `ARK_API_KEY`，或者项目根目录的 `.env`：

```bash
ARK_API_KEY=你的钥匙
```

`.env` 已被忽略，不要提交。可以按 `.env.example` 新建。钥匙只留在本机进程里，页面拿不到。

`GET /api/health` 返回 `{"ok": true, "style": true}` 时，钥匙和风格参考图都在。`ok` 为 false 时，书架和试册仍能打开，新的一册画不出来。

## 使用

1. **书架** `#/`。试册一直在。自己做成的册子留在这台浏览器里。
2. **做一本** `#/make`。一次丢进这一趟的 jpg、png 或 webp。
3. **一句话**。看完短名单后给出一句中文，外加几条可勾选的不确定情节，其中固定有「都没有，故事不是这样」。可以再补一句回忆，也可以空着。这一屏不铺照片。
4. **故事确认**。能看见分到各页的原片和那一页的中文。封面不能改成画。其余页可以点「改成画」，只保留一页画。点「就按这个做」才开始做。
5. **成图**。点头之后只画那一页。照片页和封面用原来的照片，不请求绘图。那一页失败可以再画；跳过就留下原片，后面的页继续。一页原片都没有，才不放上书架。
6. **打开一册** `#/read/<id>`。先读图文。左右按钮和点按画面左右半边换页，到头的按钮停住。文末才是「发出去」，下面是朋友圈、小红书、视频。

中文排在图下，保存文件时才画进画面。旧册没有页种类时，整张旧图铺开，不显示原来的英文。

册子存在这台浏览器的 IndexedDB，库名 `shijing`，对象库仍是 `posters`。新的一页记下 `posterId`、`kind`、`copy`。换浏览器、清站点数据，册子就没了。试册不进这个库，它直接读 `site/assets/sample/`。

服务重启后，做到一半的会话会断，需要重新丢照片。已经放上书架的册子不受影响。

## 发出去

网站不代发。保存下来的是文件，自己拿去相册或对应的应用。

**朋友圈。** 封面单独发，是 1125×1500。「保存封面」只保存这一张。后面几页是 1080×1440，「保存后面几页」保存这些页。

**小红书。** 每一页是 1080×1440 的 3:4。第一张标着「封面」。点画面左右，或点底下的小图，换一页。旁边那句可以「复制这句话」：有确认过的句子就用句子，没有就用书名。「保存这一套」一次拿走全部。

**视频。** 画面是 1080×1440。每页先完整停留约 3.5 秒，再淡到下一页。「保存视频」写成一条本地视频。这台浏览器做不成时，画面仍可以在这里看。系统要求减少动效时，预览不自动换页。

**画面。** 「保存画面」给出每一页的 1080×1440。图在上，字在下。旧册整图放进这一格，不另写英文。

手机上，浏览器允许时，保存交给系统分享，以便进相册。电脑上，多张图合成一个压缩包，单张直接下载。压缩包里的文件名是中文。

## 制作时发生什么

浏览器先把照片收成最长边 1280 的 JPEG。清晰度用拉普拉斯方差，近重复用 dHash。模糊的在已经留下两张之后丢掉（方差低于 25），哈希距离不超过 6 的当成同一张。最多留下 8 张，只把这张短名单送去看。

服务端接着按这个顺序做：

1. `POST /api/session` 开一轮制作。
2. `POST /api/photo` 逐张阅读。每张要一个场面、一个语义核、两到三个视觉锚点、一条不确定情节，以及必须丢掉的东西。单张超过 8 MB 会拒绝。
3. `POST /api/sentence` 收成一句中文和勾选项，并附上「都没有，故事不是这样」。勾了这一项，其他情节都不算数。
4. `POST /api/story` 排成最多 6 页。顺序跟回忆走，不跟文件名走。每页绑回一张短名单里的照片。封面用确认过的那句。正文是两句中文，40 到 70 字；不合格就换成固定的一句。恰好一页是画。
5. `POST /api/drawing` 把指定的正文页改成那一幅画，并返回更新后的故事。封面不能改成画。
6. `POST /api/poster` 只画 `kind` 为 `drawing` 的那一页。照片页和封面返回 400，错误是「这一页不用画」。成品写入 `site/generated/`，浏览器再存进 IndexedDB。

读照片和写故事用 `glm-5-3-flash-260828`。那一幅画用 `doubao-seedream-5-0-pro-260628`。两个都打 `https://ark.cn-beijing.volces.com/api/v3`。`/api/plan/v3` 配这把钥匙会返回 401，不要改回去。

画是竖幅，尺寸 `1536x2560`，PNG，不加水印，画面里不写字。原图只提供事实。请求里不要打开提示词优化。

## 试册

试册四页，书名「试册」：

| 页 | 图 | 文字 |
| --- | --- | --- |
| 封面 | `assets/sample/photos/terraces.jpg` | 雪停在远处，这一趟就从这里看过去。 |
| 2 | `assets/sample/photos/fog-road.jpg` | 路还在雾里，两边的树只剩一层浅色。我们没有再往前走，照片把这段空空地停在了这里。 |
| 3 | `assets/sample/03.png` | 盘子里只有一点点，手刚从右边离开。那一顿比这张画停得更久，味道一点都没被拍下来。 |
| 4 | `assets/sample/photos/alley.jpg` | 这条巷子很窄，光只落在一边的墙上。我们在这儿站了一会儿，照片没能留下说话的声音。 |

打开先看见这四页图文。封面是梯田和远处的山，配上面那句 17 个字。第二页、第四页是原片。第三页是盘子那幅画。

`demo-distill/` 留着当时的海报样张和提示词，不再当作试册。

## 这一版不做

- 把每一页都重画成海报。
- 账号、云端书架、整架备份。
- 服务中途崩溃后续画。内存里的会话不保留。
