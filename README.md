# 拾景

把一趟旅行的照片收成一本纸刊。先在本机挑照片，再确认一句故事，点头之后才逐页画成海报。

这一版只在本机运行。界面是中文。没有账号、云同步、备份包，也不往外发布。

## 启动

在项目目录运行：

```bash
python3 server.py
```

浏览器打开 [http://127.0.0.1:8765](http://127.0.0.1:8765)。服务只听 `127.0.0.1`。

画画和读照片用的钥匙放在环境变量 `ARK_API_KEY`，或者项目根目录的 `.env`：

```bash
ARK_API_KEY=你的钥匙
```

`.env` 已被忽略，不要提交。可以按 `.env.example` 新建。钥匙只留在本机进程里，页面拿不到。

`GET /api/health` 返回 `{"ok": true, "style": true}` 时，钥匙和风格参考图都在。`ok` 为 false 时，书架和试册仍能打开，新的一册画不出来。

## 使用

1. **书架** `#/`。试册一直在。自己做成的册子留在这台浏览器里。
2. **做一本** `#/make`。一次丢进这一趟的 jpg、png 或 webp。
3. **一句话**。看完短名单后给出一句中文，外加几条可勾选的不确定情节，其中固定有「都没有，故事不是这样」。可以再补一句回忆，也可以空着。
4. **故事线**。按勾选和补句重写成书名和页序。这里还没有画册。
5. **成图**。点「就按这个画」之后，一页页生成海报。某一页失败可以再画，也可以跳过。至少留下一页才会放上书架。
6. **打开一册** `#/read/<id>`。先看到三个名字：朋友圈、小红书、视频。点一个名字，看发出去的样子。原图从「保存原图」拿走。「翻册」在「放回书架」旁边，点了才进入翻页；再点一个名字就回到对应的形式。

确认阶段不铺照片墙，只显示进度、句子、勾选和故事线。海报上的短句是英文，画进画面里，不能单独改字。

册子存在这台浏览器的 IndexedDB，库名 `shijing`。换浏览器、清站点数据，册子就没了。试册不进这个库，它直接读 `site/assets/sample/`。

服务重启后，做到一半的会话会断，需要重新丢照片。已经放上书架的册子不受影响。

## 发出去

网站不代发。保存下来的是文件，自己拿去相册或对应的应用。

**朋友圈。** 高的那张单独发，方格一起发。竖封面长边不超过 1500。方格是 1080 的正方形，从海报底部裁，英文短句留在格子里。「保存封面」和「保存方格」各管一份。

**小红书。** 每一页是 1080×1440 的 3:4。第一张标着「封面」。点画面左右，或点底下的小图，换一页。旁边那句可以「复制这句话」：新册子用确认过的中文，旧册子和试册没有这句话时用书名。「保存这一套」一次拿走全部。

**视频。** 竖屏，一页一页慢翻，大约 13 秒。「保存视频」写成一条本地视频。这台浏览器做不成时，画面仍可以在这里看。

**原图。** 「保存原图」给出 3:5 母版，沿用海报原来的文件，不重新压缩。

手机上，浏览器允许时，保存交给系统分享，以便进相册。电脑上，多张图合成一个压缩包，单张直接下载。压缩包里的文件名是中文。

## 制作时发生什么

浏览器先把照片收成最长边 1280 的 JPEG。清晰度用拉普拉斯方差，近重复用 dHash。模糊的在已经留下两张之后丢掉（方差低于 25），哈希距离不超过 6 的当成同一张。最多留下 8 张，只把这张短名单送去看。

服务端接着按这个顺序做：

1. `POST /api/session` 开一轮制作。
2. `POST /api/photo` 逐张阅读。每张要一个场面、一个语义核、两到三个视觉锚点、一条不确定情节，以及海报里必须删掉的东西。单张超过 8 MB 会拒绝。
3. `POST /api/sentence` 收成一句中文和勾选项，并附上「都没有，故事不是这样」。勾了这一项，其他情节都不算数。
4. `POST /api/story` 排成最多 6 页。顺序跟回忆走，不跟文件名走。每页绑回一张短名单里的照片。英文短句最多 8 个词，写不出来时用 `A QUIET PAGE.`
5. `POST /api/poster` 按页码画一张。内容图在前，风格图在后。成品写入 `site/generated/`，浏览器再存进 IndexedDB。

读照片和写故事用 `glm-5-3-flash-260828`。海报用 `doubao-seedream-5-0-pro-260628`。两个都打 `https://ark.cn-beijing.volces.com/api/v3`。`/api/plan/v3` 配这把钥匙会返回 401，不要改回去。

海报是竖幅 3:5，尺寸 `1536x2560`，PNG，不加水印。原图只提供事实，画面要重画成暖纸上的水粉插图，上半留白，短句落在下方。请求里不要打开提示词优化，否则会把画面拉回照片。

## 试册

试册四句是：

- `THE VALLEY KEEPS THE SNOW.`
- `THE BOAT STAYS.`
- `THE PLATE IS ENOUGH.`
- `A ROOF AND A MOUNTAIN.`

原图在 `demo-distill/sources/`，是公开图片，不是一趟真实旅行。对应提示词在 `demo-distill/prompts/`。`demo-distill/index.html` 是当时单独看翻页的页面。现在打开试册先看到三种形式，翻页从「翻册」进入。

## 这一版不做

- 简易原图页。进册的每一页都是海报。
- 账号、云端书架、整架备份。
- 不重画就能改海报上的字。
- 服务中途崩溃后续画。内存里的会话不保留。
