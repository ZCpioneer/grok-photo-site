# 图文修订

这篇修订改的是已经接受的[图文成册](2026-10-11-picture-essay.md)。没被点名的条款仍以那份规格为准。成品仍是一篇最多 6 页的中文图文，照片留在页上，字在保存时才合成进画面。

## 作者的字

模型起稿。作者在草稿里改字，标题不能改。

封面那一句：去掉首尾空白后可以是空的，最长 80 个字符，不含换行，不含 ASCII 字母。不合格时接口拒绝，原来的句子留着。错误文案是「这句话先改成中文，80 字以内」。

正文：去掉首尾空白后至少有一个字符，最长 80 个字符，恰好两个句末符号（`。` `？` `！`），以句末符号结尾，不含换行，不含 ASCII 字母。可以短于 40 字。不合格时接口拒绝，原来的正文留着。错误文案是「这一页要正好两句，80 字以内」。

模型写的正文仍走原来的 `fit_copy`：40 到 70 字，否则整段换成兜底句。作者改过的字不再经过 `fit_copy`。

第二句只写照片里没有的声音、气味、温度或画框外面，不写人做了什么。人做了什么，只有用户在「补一句」里写过，才能出现。这条写进给模型的提示，不用程序判断一句里有没有动作。

试册正文改为：

- 第 2 页：`路还在雾里，两边的树只剩一层浅色。雾把脚步声吃掉了，湿气停在镜头外面，照片里没有这层冷。`
- 第 4 页：`这条巷子很窄，光只落在一边的墙上。说话的声音停在墙外面，照片里只剩下这一边的光。`
- 封面和第 3 页的字不动。

## 一句话那一屏

导语是「这句话对吗？不对就直接改它。」句子在原地改。勾选的小标题是「这几件发生过的，勾上」。固定退路的 id 仍是 `none`，文案改为「这几件都没发生」。勾了它，其他情节仍不算数。

从草稿回到这一屏时，保留已经改过的句子、已经勾上的项和补上的那一句。这一屏离开的链接写「不做了」，去书架。阅读页上的「放回书架」不动。

## 画

模型给的 `draw`：零个时正文全是照片；恰好一个时用那一页；多于一个时仍用 `max(1, (页数 - 1) // 2)`。只有一页时没有画页。封面不能是画。

草稿里被选中的那页，照片左上角标「这一页将画成插画」，按钮是「改回照片」。其余正文页是「改成画」。有画页时，底部还有「都用原片」。点「改回照片」或「都用原片」，全书不再有画页。

底部一条固定栏：主按钮「就按这个做」，旁边是「都用原片」（没有画页时不显示）和「回到勾选」。页顶的说明是「字是替你起的稿，不对的地方直接改。」封面页框里有书名和那一句，框外不再单放书名。

等待卡写「正在画第 N 页」，N 从 1 数，并显示这一页的原片。画成之后先看一屏：大图是画，旁边是原片，三个按钮是「留下这幅」「再画一次」「用原片」。失败时仍是「再画这一页」和「跳过这一页」。

## 版面

页面仍是 1080×1440。上面 1008 像素是画面区，下面是文字区。纸色 `#f3eedf`，正文 `#282923`。

横图和方图铺满画面区并居中裁切。竖图（高大于宽）整张放进画面区、居中，空出的地方留纸色。不知道宽高时先按整张放。书架格子仍是 3:5，只改格子里的图怎么放。

封面书名在 420 像素宽的页上是 28px、字距 0.12em、颜色 `#282923`。封面句子是 22px、颜色 `#6f6e64`。正文是 22px、颜色 `#282923`。导出用同一组字号和颜色，书名字距同样是 0.12em，并且算进折行宽度。字多到放不下时一起缩小，最小是这个宽度下的 8px。

折行时，`。，！？、` 不落在行首；能放的话就接到上一行末尾。

阅读页框按 1080:1440 定高。页框下居中写「2 / 4」这种页码，12px，颜色 `#8a8474`。

## 读完再发出去

「发出去」仍在页框下面，12px。三个名字是 15px。打开时一个都不选，下面不展开。再点已选中的名字，收起。

朋友圈仍是封面 1125×1500、其余页 1080×1440，不裁方格。这一屏一个主按钮：「保存这一套」。点小图只在这一屏里把那张放大，不下载。

小红书仍是每页 1080×1440，按钮仍是「保存这一套」和「复制这句话」。不再另给「保存画面」。

视频仍是 1080×1440 的本地文件。封面停留 3000 毫秒。正文停留 `min(12000, 3000 + 120 × 字数)` 毫秒，字数是这一页 `copy` 去掉首尾空白后的长度。页与页之间淡 450 毫秒。预览和保存用同一条时间。减少动态效果时，预览不自动播，保存的文件仍按这条时间。按钮旁写「约 N 秒」，N 是总毫秒数除以 1000 后四舍五入。试册这四页是「约 28 秒」。

## 说法

书架的说明是「一次丢进一趟旅行的照片。先确认一句故事，再做成图文。」制作页的提示是「先确认这篇图文」。不再使用「纸刊」。

## 接口

- `POST /api/story` 的 JSON 里如果有 `sentence`，先按封面那一句的规则收下，再拿这句去排页。没有这个字段时，沿用原来的句子。
- `POST /api/copy` 的 JSON 是 `{ session, index, copy }`。`index` 为 0 时改封面那一句，并同时改故事里的 `sentence`。其余下标改那一页正文。返回更新后的故事。
- `POST /api/drawing` 的 JSON 里 `clear` 为真时，去掉全部画页，返回故事。否则仍按 `index` 把画挪到那一页。
